DESCRIPTION: During my internship at CODTECH IT Solutions, I developed a File Handling Utility in Java as part of Task 1. The program demonstrates five core file operations — Write, Read, Append, Modify, and Delete — performed sequentially on a text file named sample.txt. Using Java's built-in java.io and java.nio.file packages, the program first creates a new file and writes initial content, then reads and displays it in the terminal, appends additional information without overwriting existing data, modifies specific text within the file by replacing "In Progress" with "Completed", and finally deletes the file after all operations are complete. Key classes used include BufferedWriter, BufferedReader, FileWriter, FileReader, Files, and Paths. The program also incorporates proper exception handling using try-catch blocks to manage IOException. Each operation is clearly labeled in the terminal output for easy understanding and traceability. This task strengthened my understanding of file management in Java, which is widely used in real-world applications such as logging systems, data storage, and configuration management. The entire program was developed and tested in VS Code using JDK 22
